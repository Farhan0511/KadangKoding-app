# 🛍️ KadangKoding Store

> Modern fashion e-commerce website built for young and dynamic lifestyles.

KadangKoding Store adalah website e-commerce fashion yang dirancang untuk menghadirkan pengalaman belanja yang **modern, clean, responsive, dan mudah digunakan**.

Project ini dibangun menggunakan **React + Vite**, dengan tampilan yang dikembangkan menggunakan **Tailwind CSS** dan komponen **shadcn/ui**.

---

## ✨ Features

* 🏠 **Modern Landing Page**
  Menampilkan hero section dan produk unggulan dengan desain yang clean dan menarik.

* 📱 **Responsive Navigation**
  Navigasi yang nyaman digunakan di desktop maupun perangkat mobile.

* 👕 **Product Showcase**
  Menampilkan koleksi fashion dengan layout yang modern dan mudah dieksplorasi.

* 💬 **Customer Testimonials**
  Menampilkan pengalaman dan feedback dari pelanggan.

* ℹ️ **About Us**
  Informasi mengenai KadangKoding dan konsep brand.

* 📩 **Contact Page**
  Halaman untuk memudahkan pelanggan menghubungi kami.

* ❓ **FAQ Section**
  Accordion FAQ untuk memberikan informasi secara ringkas dan terstruktur.

* 📬 **Newsletter Subscription**
  Pengguna dapat berlangganan untuk mendapatkan update terbaru.

* 🎨 **Modern UI**
  Menggunakan desain minimalis dengan perpaduan warna hitam, putih, dan neutral tones.

* ⚡ **Fast & Responsive**
  Dibangun dengan Vite untuk development dan build yang cepat.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone <url-repo-kamu>
```

### 2. Masuk ke Folder Project

```bash
cd kadangkoding-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Development Server

```bash
npm run dev
```

Setelah server berjalan, buka:

```text
http://localhost:5173
```

---

## 📦 Build for Production

Untuk membuat production build:

```bash
npm run build
```

Preview hasil production:

```bash
npm run preview
```

## 🎨 Design Philosophy

KadangKoding menggunakan pendekatan desain:

**Simple · Modern · Comfortable · Youthful**

Interface dibuat dengan fokus pada:

* Clean typography
* Spacious layout
* Minimal visual elements
* Strong black & white contrast
* Responsive design
* Easy navigation

Tujuannya adalah membuat pengalaman berbelanja yang terasa **simple tetapi tetap stylish**.

## 📱 Responsive Design

Website dirancang agar dapat digunakan dengan nyaman pada berbagai ukuran layar:

```text
Desktop      → 🖥️
Tablet       → 💻
Mobile       → 📱
```

Layout, navigation, typography, dan component akan menyesuaikan ukuran perangkat secara responsive.
